# Domaći Ukusi

I want you to design ONLY ONE PAGE: the homepage / landing page.

IMPORTANT:

This is a visual design task only.

Do NOT build backend functionality.

Do NOT create database logic.

Do NOT implement authentication.

Do NOT create APIs.

Do NOT modify application architecture.

Do NOT build other pages.

Do NOT spend time implementing business logic.

Focus entirely on the visual design and frontend UI/UX of this single homepage.

Product concept

This is a SaaS/platform for discovering and promoting local Serbian producers and their homemade products.

Local producers can present their:

household / farm

story

products

location

photos

contact information

Examples of products:
Ajvar, čvarci, sprža, slatko, džem, med, sir, rakija, suhomesnati proizvodi and homemade preserves.

The platform should NOT feel like a generic online shop.

It should feel like discovering:
"ljude, domaćinstva i ukuse našeg kraja."

Main design direction

Create a:

cozy + minimalistic + Serbian/Balkan etno + modern SaaS

visual identity.

The most important balance is:

TRADITIONAL FEEL
+
MODERN DIGITAL PRODUCT

Do NOT make it look like an old-fashioned Serbian folk website.

Do NOT cover the interface with ornaments, folk patterns or decorative elements.

The etno influence should be subtle, elegant and premium.

Think:

"Tradicionalno domaćinstvo predstavljeno kroz moderan digitalni proizvod."

Color palette

Use warm natural colors:

warm cream / ivory

paprika red

muted terracotta

olive green

warm brown

dark charcoal

subtle golden accents

Avoid:

SaaS blue

purple gradients

neon colors

excessive gradients

excessive glassmorphism

cold corporate colors

The website should immediately feel warm and organic.

Homepage structure

Create ONLY this homepage.

1. Navigation

Minimal, elegant navigation.

Logo / brand name on the left.

Navigation:

Početna

Proizvođači

Proizvodi

O nama

Right side:

"Predstavi svoje domaćinstvo"

Keep navigation clean and premium.

2. Hero section

This is the most important part of the page.

Create a large, visually impressive hero.

Headline:

"Ukusi našeg kraja."

Supporting text:

"Upoznajte domaćinstva, ljude i proizvode koji čuvaju tradiciju."

Primary CTA:

"Pronađi domaće"

Secondary CTA:

"Predstavi svoje domaćinstvo"

Use a large authentic photographic composition.

Visual inspiration:

red peppers

ajvar

wooden table

traditional kitchen

countryside

homemade food

hands preparing food

The photography should feel authentic and warm, NOT like generic stock photography.

3. Category discovery

Below the hero, create a simple section:

"Šta tražite?"

Show beautiful category cards:

Ajvar i zimnica

Suhomesnato

Mlečni proizvodi

Med

Slatko i džemovi

Domaća pića

Use imagery and subtle etno details.

4. Featured producers

Section title:

"Domaćinstva sa pričom."

Show 3–4 producer cards.

Each card should contain:

large photo

household name

location

short description

category tags

"Pogledaj domaćinstvo"

Example:

Domaćinstvo Nićić
Leskovac, Srbija

The cards should feel more like discovering a family business than shopping for a product.

5. Storytelling section

Create one strong editorial section:

"Iza svakog proizvoda stoje ljudi."

Large photograph on one side.

Text on the other.

Explain visually that the platform is about:

family

tradition

local production

craftsmanship

authentic ingredients

This section should have an editorial / magazine feeling.

6. Featured products

Section:

"Ukusi koji se pamte."

Create a clean product grid with products such as:

Domaći ajvar

Čvarci

Sprža

Šljiva slatko

Domaći med

Use beautiful product photography.

Do NOT make this look like Amazon or a standard e-commerce website.

7. Producer CTA

Create a warm final CTA section:

"Imate svoje domaćinstvo?"

"Predstavite svoje proizvode i priču ljudima koji traže domaće."

Button:

"Predstavi svoje domaćinstvo"

8. Footer

Simple minimal footer with:

logo

navigation

contact

social links

Visual language

Use:

generous whitespace

warm backgrounds

subtle borders

soft shadows

slightly rounded cards

large photography

editorial typography

organic shapes

Use subtle etno references such as:

very small traditional textile-inspired details

hand-drawn separators

wheat / pepper / leaf motifs

subtle paper texture

BUT KEEP THEM VERY SUBTLE.

The design should still look like a professional modern SaaS product.

Typography

Use a modern sans-serif for UI.

Use a tasteful serif/editorial font for selected large headings.

Typography should feel:

warm

premium

human

modern

editorial

Avoid decorative folk fonts.

Important

Do NOT design additional pages.

Do NOT create dashboards.

Do NOT create authentication pages.

Do NOT create product detail pages.

Do NOT create producer profile pages.

Do NOT implement backend.

Do NOT focus on functionality.

I want to use this single homepage to evaluate the visual direction before designing the rest of the application.

The final result should make someone immediately think:

"Ovo je moderno mesto za otkrivanje domaćih proizvođača i ukusa našeg kraja."
